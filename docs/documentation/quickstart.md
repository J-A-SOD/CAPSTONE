## H2 Header: Links, Images, and Code

### Hyperlinks
You can easily link to an [External Website](https://example.com) or reference a local project document like an [Internal README](README.md).

### Code Snippets

If you want to reference `inline code`, surround it with single backticks. For blocks of code, use triple backticks and specify the language for syntax highlighting:

```python
# This is a sample Python code block
def greet_user(name):
    print(f"Hello, {name}! Welcome to Markdown.")

greet_user("Developer")
```
